# Victoria Perfume Store

A perfume e-commerce website built with HTML, CSS and JavaScript.

This project provides an interactive shopping experience. After entering the website, users receive a random discount code after a few seconds.

Users can add products to the shopping cart, change the quantity, and see the total price. The website also includes discount code verification and price calculation features.

## Features

- Interactive shopping cart
- Random discount code generation
- Add products to cart
- Change product quantity
- Calculate total price
- Discount code verification
